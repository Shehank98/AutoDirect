The Our Stock page body: filter sidebar, sort, grid/list toggle, removable filter chips, empty state and compare tray.

## Props

`vehicles`, `initialCompare` (ids), `onOpen(vehicle)`, `onCompare(vehicles)`.

## Usage

Filters: search, make, body type, price, year, minimum auction grade, show sold. Under 960px filters open as a full-screen sheet. Compare is capped at 4.
