Live auction lot: countdown, current bid (¥ and ≈ LKR), proxy maximum stepper and bid states.

## Props

`lot` {lot, house, date, make, model, grade, year, chassis, mileage, auctionGrade, interior, current, endsIn (s), img}.

## Usage

Countdown turns vermilion under an hour. A maximum at or below the current bid shows an inline error.
