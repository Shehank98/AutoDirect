Two-tier site header: dark info bar (phone, email, locations, live-auction ticker) and the main nav.

## Props

`active` (home, stock, auction, buy, sheet, vocab, compare, about, contact), `onNavigate(id)`, `compareCount`, `user` (name → account menu; absent → Sign in).

## Usage

Keeps every page of the old site one click away; "How to buy" groups the buying process, auction sheet guide and vocabulary. Collapses to a burger under 1080px.
