Labelled text input with hint, error, icon, prefix and trailing slot.

## Props

`label`, `hint`, `error`, `icon`, `prefix` (e.g. LKR), `trailing` (node), `mono`, `multiline`, `optional`, plus native input props.

## Usage

Errors say how to fix it ("Use a Sri Lankan mobile, e.g. 077 123 4567."). Use `mono` for chassis codes and reference numbers.
