Line icon set drawn on a 24px grid with a 1.75 stroke, inheriting `currentColor`.

## Props

`name`, `size` (default 18), `stroke`, `label` (gives it role=img; otherwise aria-hidden).

## Usage

Pair icons with text; icon-only buttons need an `aria-label`. Names: search, car, gavel, compare, heart, gauge, fuel, gear, calendar, ship, doc, shield, pin, phone, whatsapp, mail, user, clock, bell, filter, grid, list, star, lock, and more in the bundle.
