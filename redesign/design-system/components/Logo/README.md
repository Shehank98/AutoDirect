The AutoDirect wordmark: a vermilion 直 ("direct") hanko seal plus "Auto**Direct**" set in Bricolage Grotesque.

## Props

`size` (px, default 22), `inverse` (on `surface-inverse`; "Direct" turns `highlight`), `suffix` (e.g. `.lk`).

## Usage

Use in the header, footer, auth card and admin sidebar. Never recolour the seal; never set the word in another face. Minimum size 16px.
