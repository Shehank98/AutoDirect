Stock listing card: photo, status, grade seal, ref + chassis, key specs, price, compare and save.

## Props

`vehicle`, `layout` (card | row), `compared`, `onCompare`, `compareDisabled`, `saved`, `onSave`, `onOpen`.

## Usage

No photo yet → striped "Photos after inspection" placeholder, never a stock image. Sold cars go greyscale with a struck price.
