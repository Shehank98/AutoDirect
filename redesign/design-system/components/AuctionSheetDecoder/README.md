Interactive guide to reading an auction sheet: tappable damage map, free-text code decoder, grade scale and a link to a real annotated sheet.

## Props

`showSheet` (default true).

## Usage

Replaces the old static "How to read auction sheet" page. Codes: A scratch, U dent, B dent+scratch, W wave/repair, S rust, C corrosion, P paint, X replace, XX replaced, Y crack, G glass chip; 1–3 = size.
